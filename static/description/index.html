🖨️ POS Print Last Receipt

Reprint the last receipt with one click!

📋 Description

This module adds a convenient "Print Last Receipt" button to your Odoo 18 Point of Sale interface. It allows cashiers to quickly reprint the last receipt without navigating through order history.

✨ Features

🎯 One-Click Printing
Print the last receipt with a single click from the POS action pad.
🔍 Automatic Detection
Automatically finds and prints the last paid order from the current session.
📄 Standard Template
Uses Odoo's default receipt template for consistency.
🔔 User Notifications
Clear success and error messages keep users informed.
💡 Easy Integration
Seamlessly integrates into the existing POS interface.

🚀 Installation

  1. Copy the module folder to your Odoo addons directory
  2. Restart your Odoo server
  3. Update the apps list (Apps → Update Apps List)
  4. Search for "POS Print Last Receipt"
  5. Click the "Install" button

📖 Usage

  • Open your Point of Sale
  • Complete at least one sale
  • Find the "Print Last" button in the action pad
  • Click to reprint the last receipt
